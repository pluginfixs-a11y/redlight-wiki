Сервер RedLightMC работает на **Fabric 1.21.11** и использует кастомные моды, расширяющие геймплей.

## Обязательный модпак

!!! info "Как установить"
    Скачайте моды из нашего [Discord](https://discord.gg/Krrnkv3Zxz) и поместите `.jar` файлы в папку `mods` вашего клиента.

## Список модов

| Мод | Версия | Описание |
|-----|--------|----------|
| **Voxy** | 1.21.11 | оптимизация и дальность прорисовки |
| **Voxy Server-Side** | 1.21.11 | аддон для voxy, нужен для шикарных видов |
| **Plasmo Voice** | 1.21.11 | голосовой чат прямо в игре |
| **Custom Player Models** | 1.21.11 | кастомные модели персонажей |
| **Emotecraft** | 1.21.11 | эмоции и анимации |
| **PatPat** | 1.21.11 | поглаживания других игроков] |
