## 1. Установка клиента

Сервер работает на **Fabric 1.21.1**. Для входа вам понадобится:

1. Лицензионный Minecraft (или пиратский лаунчер — укажите своё)
2. Установленный Fabric Loader для версии 1.21.1
3. Наш модпак (опционально — укажите, нужен ли он)

!!! info "Модпак"
    Скачать актуальную сборку модов можно в нашем [Discord](https://discord.gg/ВАША_ССЫЛКА).

## 2. Регистрация

При первом входе на сервер зарегистрируйтесь:

```
/register <пароль> <пароль>
```

При последующих входах:

```
/login <пароль>
```

## 3. Первые шаги

### Случайная телепортация

Чтобы найти место для базы, используйте:

```
/rtp
```

### Основные команды

| Команда | Описание |
|---------|----------|
| `/spawn` | Телепорт на спавн |
| `/home` | Телепорт домой |
| `/sethome` | Установить точку дома |
| `/tpa <ник>` | Запрос на телепортацию к игроку |
| `/rtp` | Случайная телепортация |
| `/balance` | Проверить баланс |
| `/shop` | Открыть магазин |

## 4. Заработок

- Продавайте ресурсы в магазине (`/shop`)
- Выполняйте квесты и достижения
- Торгуйте с другими игроками

## 5. Полезные советы

!!! tip "Совет новичку"
    Не торопитесь строить огромный дом сразу. Сначала найдите безопасное место, обеспечьте себя едой и базовыми ресурсами.

- Сохраняйте координаты базы (`F3`)
- Используйте `/sethome`, чтобы не потеряться
- Заходите в Discord, чтобы найти соседей и союзников
