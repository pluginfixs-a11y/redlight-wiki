# Как начать играть

## 1. Установка клиента

Сервер работает на **Fabric 1.21.11**. Для входа вам понадобится:

1. Любой Minecraft лаунчер
2. Установленный Fabric Loader для версии 1.21.11
3. Моды для хорошей игры на сервере

!!! info "Модпак"
    Скачать актуальную сборку модов можно в нашем [Discord](https://discord.gg/Krrnkv3Zxz).

## 2. Регистрация

При первом входе на сервер зарегистрируйтесь:

```
/register <пароль> <пароль>
```

При последующих входах:

```
/login <пароль>
```

## 3. Первые шаги


### Основные команды

| Команда | Описание |
|---------|----------|
| `/skin` | Установка своего скина |
| `/size` | Установка своего размера |
| `/info` | Получить список всех команд и информацию |
| `/image2map` | Сделать свою карту |
| `/ledger i` | Узнать кто воровал ресурсы |
| `/lazodisc` | Сделать custom пластинку |
| `/group` | Создать/зайти в группу войса |
